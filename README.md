# 메모앱 — 설치 가능한 합성 자료용 Windows 시험판

Windows 관리창·포스트잇을 중심으로 개발 중인 S메모 대체 앱입니다. 현재 일반 메모/폴더·태그·검색·암호 휴지통·수정이력·수동 암호백업과 포스트잇·잠금·파일 후보 복구를 연결했습니다. **서명 없는 합성 자료용 시험판**이며 Windows CI에서 빌드·실행 검사합니다. Windows Server CI에서 실제 WPF 제어·바인딩·검색·공유편집·잠금/Undo 동작을 자동시험했습니다. 실제 한글 IME/OS 잠금/다른 계정/USB/다중모니터 사용자 흐름은 아직 미검증입니다. 실제 개인정보나 기존 S메모 자료를 넣거나 이전하지 마세요. 전체 134 기능 완료/실제 개인정보 사용 준비 완료가 아닙니다.

현재 다운로드 가능한 OCR·자동 휴지통 정리 포함 설치 시험판은 [다운로드](https://github.com/choehongseok/memo-app/actions/runs/37995989631/artifacts/11647312201)에서 받을 수 있습니다. 산출물 ID·ZIP 해시·검증 커밋·남은 범위는 [인계 기록](docs/WINDOWS-TRIAL-2026-10-09.md)에 있습니다.

## 실행과 첫 사용
Windows x64 시험판 zip 전체를 새 폴더에 압축 해제하고 `MemoApp.Windows.exe`를 실행합니다. .NET 런타임을 포함한 self-contained 패키지입니다. 사용자 폴더 설치형과 portable 실행을 제공합니다. 서명/자동 업데이트는 없습니다. OS/기관 PC 정책을 우회하지 마세요.

설치형은 `Install-User.cmd`를 실행하고 확인창에서 `%LOCALAPPDATA%\Programs\MemoApp\SyntheticTrial`의 새 설치를 승인합니다. 시작 메뉴 `MemoApp Synthetic Trial` 또는 설치 폴더의 exe로 실행합니다. 관리자 권한은 사용하지 않으며 기존 설치가 있으면 덮어쓰지 않고 거절합니다. 바로가기 실패 시 설치 폴더의 exe로 실행할 수 있습니다. 패키지 manifest의 SHA256은 파일 손상 검사이며 배포자 서명이 아닙니다. portable은 `Start-Portable.cmd`를 사용합니다.

1. 새 자료용 복구 비밀을 생성해 오프라인에 보관하고 정확히 다시 입력해 자료를 만듭니다. 비밀은 43글자이며 자동 클립보드 복사/로그 기록은 하지 않습니다. 비밀을 잃으면 복구할 수 없습니다.
2. 새 메모의 제목·일반 본문을 편집하면 약 0.7초마다 암호 저장을 시도합니다. 관리창의 변경됨/저장 중/저장됨/실패 상태를 확인합니다. 포스트잇과 관리창은 같은 메모 편집 상태를 공유합니다.
3. 파일 → 완전히 종료 또는 창 닫기는 마지막 저장·잠금 완료를 기다립니다. 다시 실행해 같은 복구 비밀로 해제하면 저장한 합성 메모를 불러옵니다.
4. 잠금/5분 idle/OS SessionLock 연결은 즉시 화면·독립창을 숨기고 키를 종료하도록 작성했습니다. Windows 실제 이벤트/화면 동작은 미검증입니다. DPAPI 자동 접근은 꺼짐·미제공, Hello와 비밀번호 해제도 미제공입니다.

자료 폴더: `%LOCALAPPDATA%\MemoApp\SyntheticTrial`. `current.vault`와 `previous-*.vault`/`pending-*.vault`는 암호문입니다. 복구 비밀 평문은 파일에 저장하지 않습니다. 이전 파일은 자동 삭제하지 않아 디스크 사용량이 늘 수 있습니다.

## 백업·복구·이전
앱을 완전히 종료한 뒤 자료 폴더의 암호 파일을 별도 안전한 위치에 복사합니다. 관리창의 암호 백업은 최신 저장 완료 후 새 파일에 암호문을 복사합니다. 기존 파일을 덮어쓰지 않으며 자료폴더 안에는 백업할 수 없습니다. 저장 후/UTC 하루 한 번/완전 종료 시 자동 암호 백업을 선택할 수 있습니다. 기본은 현재 해제 세션만이며, `재실행 뒤 이 기기에 복원`을 직접 선택하면 이 기기 프로필의 조건을 암호 저장한 뒤 활성화합니다. 같은 저장소 폴더의 네이티브 ID까지 일치해야 재해제 뒤 복원하며, 다른 폴더로 복사하거나 명시 후보 복구를 하면 다시 선택해야 합니다. 하루 시도 날짜를 저장한 뒤 복사하므로 복사 실패·재실행·시계 역행 때 같은 저장 날짜를 중복 시도하지 않습니다. 날짜 예약 저장 자체가 실패하면 백업은 만들지 않습니다. 현재 실행에서는 같은 날 재시도를 억제하지만 재실행에는 마지막으로 저장한 날짜만 복원합니다. 잠금 중에는 실행하지 않으며 다음 해제 뒤 한 번 시도합니다. 설정을 바꾸는 중 실패하면 자동 실행은 꺼지지만 마지막 저장 설정은 재실행 때 남을 수 있으므로 안내와 저장 상태를 확인하세요. 지속 설정을 사용한 schema9 자료는 이전 앱으로 수정하지 마세요. 보관 한도 1~100개에 도달하면 기존 백업을 보존하고 중단합니다. 암호 파일 복사에도 복구 비밀이 필요하며 파일 안에는 암호화된 키 복구 정보가 포함됩니다.

다른 시험 폴더/PC에서 파일을 가져오려면 잠금 화면에 복구 비밀을 입력하고 '암호문 사본 가져와 후보로 보존'을 사용합니다. 사본 인증 후 후보로 보존하며 적용하려면 후보를 골라 명시적으로 복구합니다. 다른 Windows 계정/PC 실사용은 미검증입니다. 복구는 새 키 epoch의 snapshot을 만들고 기존 파일·정상 후보를 보존합니다. 해제 상태의 백업 미리보기에서는 선택한 메모를 새 ID의 사본으로 복구할 수 있습니다. 원본 백업과 현재 메모는 보존하며 동기화 병합·S메모 고유 형식 가져오기는 미제공입니다.

저장 오류는 쓰기를 중단하고 기존/보류 파일을 보존합니다. 잠금 중 암호문 보류 상태이면 사본 저장 후 후보로 복구할 수 있습니다. 암호화 전 실패는 화면을 가린 '숨겨진 복구 대기·메모리 키 보유'로 표시하고 같은 비밀로 편집을 재개합니다. 미저장 변경을 버리고 종료/재해제하는 동작은 별도 확인이 있습니다. 유효한 과거 파일 전체 replay는 AEAD만으로 검출하지 못하며 전원 장애의 완전 내구성을 보장하지 않습니다.

## TXT·포터블·순서
- TXT 가져오기는 UTF8 또는 BOM UTF16LE/BE만 지원합니다. 1MiB/65536 UTF16 단위 한도를 지키고 원본을 수정하지 않습니다. ANSI추측·UTF32·binary·네트워크/링크경로는 거절합니다
- TXT 내보내기는 위험확인 후 제목·본문의 평문 UTF8사본을 새파일로 저장합니다. 기존파일/현재vault 안에는 쓰지 않습니다. 외부앱/백업에 남은 TXT는 앱잠금으로 보호할 수 없고 실패시 부분평문파일이 남을 수 있습니다
- Start-Portable.cmd 또는 MemoApp.Windows.exe --portable은 exe옆Data를 사용합니다. 기본실행은 기존LocalAppData를 유지하며 실패해도 다른폴더로 자동전환하지 않습니다. 복구비밀은 따로 보관하세요
- 사용자순서 정렬에서 ↑↓/메모카드 drag로 위치를 바꿉니다. 목록고정그룹은 별도이며 folder/검색filter 밖 메모의 상대순서와 내용은 보존합니다. 실제물리drag/다중모니터/USB시험은 미검증입니다
- 경로검사는 악의적인 동시junction교체의 완전한 handle 기반방어를 보장하지 않습니다. 계속합성자료만 사용하세요

## 일괄 처리·이력 비교
Ctrl/Shift로 여러 메모를 선택하면 단일 본문 편집/복제/태그/내보내기를 막고 일괄 이동·암호휴지통·복원 명령을 사용할 수 있습니다. 모든 선택을 먼저 검증하고 한 대상의 한도 오류도 전체 적용을 거절합니다. 처리 후 암호 저장에 실패하면 반영된 미저장 변경을 구분해 안내합니다. 영구삭제는 제공하지 않습니다.

수정 이력의 날짜별 비교에서는 열었을 때 저장된 head와 과거 고유revision을 읽기 전용으로 대조합니다. 제목·분류/표시 metadata와 본문의 줄 추가/삭제를 표시하며 Unicode와 줄 끝을 정규화하지 않습니다. 계산/라인/출력 한도 초과는 완전한 비교라고 표시하지 않고 양쪽 원문을 유지합니다. 복원은 비교와 독립된 명시 확인 동작입니다.

## 장치별 창·표시 설정과 날짜 위젯
- 메모 위치/크기·모니터·항상위·투명도·접기·위치 고정 및 열림 여부를 암호 자료에 장치별로 보존합니다. 해제하면 해당 장치에서 열려 있던 활성 메모를 다시 엽니다. 사용자가 창을 닫으면 닫힘을 기록하고 앱잠금은 열림 의도를 유지합니다
- 숨김/표시와 화면 정렬은 해제 상태에서만 동작합니다. 정렬은 작업 영역 안으로 크기/위치를 제한합니다. 다중모니터·혼합DPI·화면분리·Windows Snap/물리키보드 위치고정은 실제 사용자 검증이 필요합니다
- 다크모드/글자크기12~36/화면배율0.75~1.75는 관리창·포스트잇·이력·날짜위젯에 적용합니다. UI 배율은 OS DPI 계산과 독립이며 큰 화면배율에서는 스크롤을 사용합니다
- 날짜달력과 시계는 로컬 날짜 표시만 제공합니다. 일정·할일·알림·계정 연결은 아직 없습니다. 잠금은 모든 날짜위젯도 닫습니다
- 장치 표시 UUID는 `%LOCALAPPDATA%\MemoApp\ui-device.id`의 32byte 비밀 아닌 식별자입니다. 메모/키/인증정보는 포함하지 않으며 portable Data와 분리되어 다른 PC에 창좌표를 강제하지 않습니다. 식별자가 손상되면 자동 교체하지 않고 실행을 거절합니다. 기존파일을 보존한 채 오류를 보고해 주세요

## schema 3 이전
이전 schema1/2 시험자료는 내용/ID/이력을 메모리에서 불러오고 첫 저장에서 schema3로 이전합니다. 원본 암호 파일을 previous 후보로 보존합니다. schema3를 이전 앱으로 편집할 수 없으며 버전 오류를 무시하거나 원본을 덮어쓰지 마세요. 합성자료만 사용하고 이전 전 앱을 종료하여 암호문 사본도 따로 보관하세요.

## 원본 파일 첨부 (현재 소스 기준)
관리창과 포스트잇에서 '파일 첨부'로 로컬 일반 파일을 선택합니다. PDF·Word·Excel·한글 파일 등은 원본 바이트와 이름·길이·SHA256을 암호 객체로 보존하며 내용은 파싱하거나 자동 실행하지 않습니다. 원본 파일은 바꾸지 않습니다. 첨부 준비와 최종 암호 저장이 성공했을 때만 저장 완료를 표시합니다.

파일당4MiB, 메모당16개, 모든 보존 파일 합계8MiB, 객체128개 및 전체 암호 파일16MiB/이력 한도가 함께 적용됩니다. 초과하면 추가 전체를 거절합니다. '선택 첨부 분리'는 현재 참조만 새 리비전으로 제거하며 원래 암호 객체와 이력·복제·백업을 보존하므로 보존 용량이 즉시 줄지는 않습니다. 영구삭제는 제공하지 않습니다.

전체 검색은 제목·본문·현재 첨부 이름을 포함하고 '첨부 이름·확장자'로 범위를 좁힐 수 있습니다. 파일 본문을 자동으로 검색하지 않습니다. OCR 결과를 새 메모로 적용하면 일반 본문 검색에 포함됩니다. 선택 PNG 첨부의 '선택 이미지 미리보기'를 명시적으로 누르면 관리창/포스트잇에 표시합니다. RGB/RGBA 8-bit, IHDR/IDAT/IEND만 포함한 비인터레이스 PNG만 지원합니다. JPEG·색상 프로필/메타데이터/팔레트/애니메이션 등 제한 밖 파일의 미리보기는 거절하지만 원본 첨부는 보존합니다. 원본 최대4MiB/축4096/4,194,304픽셀, 표시 최대1024축/4MiB BGRA입니다.

앱 전체에서 한 작업과 한 표시 이미지만 허용합니다. 처리 중 다른 요청은 복호화하지 않고 재시도 안내를 표시합니다. 선택 변경·편집·분리·잠금·창 종료 시 오래된 결과를 폐기하고 표시를 해제합니다. native/GPU 메모리의 즉시 소거는 보장하지 않습니다. 인라인 문서 이미지는 미제공입니다. 별도 명시 PNG 클립보드 입력/로컬 이미지 파일 드롭/파일 경로 연결/첨부 외부 열기·평문 내보내기는 각 확인과 입력 제한을 따릅니다.

로컬 OCR은 선택 PNG에서 명시적으로 사용합니다. `OCR 모델 설치`로 암호 자료 폴더 밖의 새 폴더에 고정 한글·영문 공개 모델과 Apache 2.0 안내(5.53 MiB)를 설치하거나 `설치 모델 선택`으로 기존 폴더를 확인합니다. 창/재실행마다 기본 꺼짐이며 자동 다운로드는 없습니다. `선택 PNG 글자 추출` 뒤 결과를 확인하고 `OCR 결과를 새 메모로`를 누르면 원본을 유지하며 별도 일반 메모로 암호 저장합니다. 인식 오류·시간/출력 제한으로 실패할 수 있습니다. 잠금·선택/원본 변경 시 미리보기는 폐기합니다.

첨부 root를 준비하면 envelope2/schema5로 저장합니다. 이전 앱은 이 형식을 읽거나 쓰지 못하므로 합성 자료로만 시험하고 별도 암호 백업을 보관하세요. 최신 source의 Windows 자동검사는 통과했지만 물리 OS·사용자 수용은 미확인입니다. 다운로드한 패키지의 installation-manifest.json에서 sourceCommit을 확인하세요. 기존818a531 시험판에는 이 후속 첨부 UI가 포함되지 않습니다.

## 최근 연결 기능의 시험 범위

현재 저장소 후속 개발판에는 Word 지원 글자 서식·목록·표 내보내기와 Excel 숫자 원문·TRUE/FALSE 가져오기가 추가됐습니다. Word 링크는 주소 문자이며 rendered Markdown은 source literal입니다. 후속 개발판은 지원된 canonical inlinePNG만 원본 바이트로 포함하고 별도 첨부·OCR·이력은 포함하지 않습니다. Excel에서는 시트와 제목·본문 열 번호, 첫 행 제외 여부를 명시 선택할 수 있습니다. 기존 첫 시트 제목·본문 템플릿도 별도 선택할 수 있으며, 날짜는 숫자 일련번호로 유지하고 수식은 거절합니다. 목록 확인 뒤 원본 파일이 바뀌면 가져오지 않습니다. 기존 d8bccaab 설치 ZIP에는 이 후속 기능이 포함되지 않습니다. 새 Windows gate 결과와 산출물을 별도로 확인하세요.
트레이 상주는 기본 꺼짐이며 현재 세션에서 선택합니다. 관리창 닫기는 상주를 켠 경우 숨김이고, `완전히 종료`는 종료입니다. Windows 시작 실행도 직접 선택해야 켜지며 현재 계정의 고정 앱 항목만 관리합니다. 설치 자체는 시작 실행을 등록하지 않습니다. 실제 로그인·Explorer 재시작·OS 전체 종료 직전 저장은 USER-TESTS에서 확인합니다.

PDF 내보내기는 제목과 검증된 본문을 평문 PDF1.7로 복사합니다. 한글 완성형·지원되는 한자·영문 등은 전체 OFL D2Coding 글꼴을 포함하며, 글꼴 고지는 `licenses/D2Coding1.4.0-OFL.txt`입니다. 최대100메모/256쪽/16MiB이고, 복잡한 문자 조합·emoji·없는 글리프는 파일을 만들기 전에 거절합니다. 원본 서식·첨부는 PDF에 포함되지 않으며 Markdown은 문자 그대로입니다. PDF/Office/외부 열기의 평문 사본과 외부 프로그램 캐시는 사용자가 관리합니다.

파일 경로 연결은 파일을 복사하거나 암호화하지 않고, 암호화된 메모 안에 기기 식별자와 경로를 보관합니다. 다른 기기의 경로는 열지 않습니다. 분리는 외부 원본을 삭제하지 않습니다. 경로 연결을 사용한 schema7 자료는 과거 버전 앱으로 수정하지 마세요. 원본과 별도 암호 백업을 보존합니다.


## 암호 백업 후 휴지통 자동 정리
기본은 꺼짐입니다. 관리창에서 7/30/90일보다 오래된 휴지통 메모의 정리 조건을 확인하고 암호 자료 폴더 밖의 기존 로컬 백업 폴더를 선택해야 켜집니다. 현재 해제 세션에서 UTC 하루 한 번만 시도하며 잠금·재실행하면 꺼집니다. 삭제 시각이 보존 기간 경계와 같거나 미래인 메모는 정리하지 않습니다. 백업에 필요한 복구 비밀은 별도로 보관하세요.

먼저 저장과 새 암호 백업을 확인한 뒤 현재 자료의 해당 메모 본문·내용 이력과 기기별 창/최근 참조를 제거합니다. 실패하거나 잠금·변경으로 백업이 오래되면 제거하지 않습니다. 적용 후 저장 실패 시 변경·백업·복구 후보를 보존하고 자동 정리를 중단합니다. 기존 백업100개 한도/삭제 표식100개/삭제 관계 이력 한도에 도달하면 기존 기록을 삭제하지 않고 멈춥니다.

백업·previous/pending 파일·암호 첨부 객체는 남으므로 완전 삭제가 아닙니다. 삭제한 메모를 되살릴 때는 정리 전 암호 백업에서 새 ID의 사본으로 복구하세요. 정리를 사용한 schema8 자료를 이전 앱으로 수정하지 말고 별도 암호 백업을 보존하세요. 실제 기존 사용자 자료의 자동 삭제 시험은 수행하지 않았습니다.

## 후속 이미지 문서 소스 (기존 ZIP 미포함)

H01은 이미 인증된 PNG 첨부를 서식 문서의 블록 경계에 명시 추가하는 문서 v2/스키마10을 연결합니다. v2 화면은 읽기 전용 순서·서식 표시와 수동 이미지 표시·제거·맨 뒤 추가를 제공하며, native 편집기 안의 자유 배치·크기 조절은 아직 지원하지 않습니다. 제거는 첨부 원본·이력을 삭제하지 않습니다. 잠금·선택·원본 변경 때 이미지를 폐기하고 앱 전체 이미지/OCR 작업을 하나로 제한합니다. 후속 Word 내보내기는 지원된 v2 inlinePNG를 실제 인증·decoder 검증 뒤 원본 그대로 DOCX에 포함하며 전체 암호 이전 파일로 문서와 원본 첨부를 보존할 수 있습니다. schema10 자료를 이전 앱으로 수정하지 마세요.

H08은 8-bit gray/gray-alpha PNG를 기존 RGB/RGBA와 함께 제한된 managed decoder에 연결합니다. palette·낮은/16-bit·interlace·tRNS·일반 JPEG 지원은 아직 아닙니다. 후속 Windows3012351의 이미지 그룹은 통과했으며 새 설치 산출물은 아직 없습니다. 위 기존 d8bccaab 다운로드에는 포함되지 않습니다.

후속 H02는 클립보드 PNG를 먼저 읽고, 없으면 4 MiB 이하 CF_DIB의 40바이트 헤더·비압축24/32비트 픽셀을 RGB PNG로 변환해 명시 암호 첨부합니다. 첨부 영역 Ctrl+V와 버튼만 연결하며 편집기 안의 이미지 붙여넣기는 아직 아닙니다. DIBV5·다른 압축·큰 스크린샷은 거절하고 Windows 자체 형식 합성 여부를 보장하지 않습니다. 후속 Windows3012351의 DIB 표시/잠금 그룹은 통과했으며 새 설치 파일은 아직 없습니다. 표시 PDF 메뉴는 후속 소스에 연결되어 있지만 별도의 native 픽셀 비교는 아래 상태대로 수정 중입니다.

후속 개발 소스에는 현재 메모를 유지하는 **백업 이력 보존**과 **보존된 백업 분기 비교**, 텍스트/표시 PDF 방식 선택이 추가되어 있습니다. 실제 Windows 새 검사와 새 설치 패키지는 아직 대기이며, 위 기존 d8bccaab ZIP에 포함된 기능으로 안내하지 않습니다. 표시 PDF의 불투명 배경은 통과했고, Windows3012351의 독립 글자 픽셀 비교에서 발견한 14픽셀 기준선 차이를 f1f1cef 소스에서 수정했습니다. 수정 뒤 세 Unicode vector는 통과했지만 emoji에서 local/global text guideline frame 차이가 발견됐습니다. localdraw-frame을 맞춘 수정은 새Windows gate 대기이며 전체 N02 완료가 아닙니다.

후속 개발 소스에는 명시적인 첨부 검색용 OCR 결과 저장(schema11)이 추가되어 있습니다. 기존 본문과 원본 이미지 대신 선택 메모의 첨부 검색 정보에 저장하며, 같은 이미지를 참조하는 다른 메모에는 적용하지 않습니다. Windows3012351의 실제 고정 OCR runtime·첨부 검색 저장 UI 검사는 통과했습니다. 이 형식으로 저장한 자료는 schema11을 이해하는 새 앱으로 열어야 하며, 위 기존 d8bccaab ZIP에는 이 지원이 없습니다. 이전 원본 암호 백업은 별도로 보존하세요.

현재 소스는 보존된 같은 메모의 live maximal 분기를 명시 선택하여 현재 내용을 유지하는 두 부모 이력으로 확인할 수 있습니다. 기존 이력과 다른 분기는 보존합니다. Windows3012351의 마지막 저장 오류 fixture 가정을 실제 쓰기 중단·암호문 후보 복구 경로로 수정했고 f1f1cef의 실제Windows 분기확인/복구검사는 통과했습니다. 자동 검사와 실제 사용자 수용은 구분하며 새 최종 ZIP 링크가 생기기 전까지 위 d8bccaab ZIP을 후속 개발판으로 사용하지 마세요.
