# Text transfer, portable launch and custom order
Continue independent selected Windows functionality after the organization unit. Keep the 134 IDs, original bytes, reviewed AEAD envelope and draft PR. Synthetic files only. No main merge, new authentication, paid services or public deployment.

- TXT read: explicit selected regular file, no reparse point/linked ancestor, at most 1 MiB source and 65,536 UTF-16 units decoded; strict UTF-8 (optional BOM) or BOM UTF-16LE/BE only. Reject guessed ANSI, binary NUL and malformed sequences. Preserve source bytes and return source SHA256. Normalize only line endings to LF in the draft. Apply only while the same session remains unlocked.
- TXT write: explicit plaintext warning and selected destination, active unlocked draft, bounded title/body, UTF-8 with CRLF and optional title. CreateNew+disk flush, never overwrite or automatically open the file. Reject linked output directories. Explain that plaintext copies and external backup caches may remain. Lock/epoch guards block late UI success or importing into a new session.
- Portable: default per-user AppData stays. Only --portable selects exe-side Data; reject unknown/ambiguous switches. Same encrypted files/secret and write/reparse refusal behavior. Provide Start-Portable.cmd. No registry/install/security-setting change.
- Custom order: existing encrypted NoteMetadata.Order, deterministic stable order, ReorderBefore verifies owned/unlocked non-trash drafts. Keep list-pinning separate. Preflight one complete next snapshot containing all shifted notes and immutable revision metadata before changing any draft; reject overflow without partial mutation. Drag payload is only a bounded UUID, resolves current internal note, and never opens files or executes text.

Test-first runtime checks cover actual strict text files, source hashing/preservation, UTF8/UTF16/binary/oversize cases, no-overwrite/closed export, startup selection, actual search custom order, no-op and foreign/overflow guards. WPF tests cover binding-ready text input, custom order UI and lock clearing. Cross-build and actual Windows runner evidence stay separate from IME/OS SessionLock/ACL/user acceptance.

Independent read-only design and actual-diff review completed. Five P1 issues found and fixed: public import notifications preceding accepted basis, linked ancestor lookup order, portable ancestor omission, a second source-length query, and cancellation while CreateNew blocked. Regression tests reproduce notification-edit loss, cancellation-before-first-write, and atomic history/payload rejection. Silent note registration/subscription and stage→accept→dirty→public publication now preserve reentrant edits/close. Read size is captured once, parents are audited root→leaf, portable Data and all parents are checked, and cancellation is rechecked after CreateNew. Post-import UI also rechecks session/epoch/membership. Reviewer read code/tests and author evidence without independently executing tests. No new product PackageReference.

Remaining limits: this is not handle-based protection against malicious concurrent path replacement; an already-started plaintext write cannot be recalled.
