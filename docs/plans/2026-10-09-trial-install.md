# Unsigned per-user Windows trial installation
User's installable Windows handoff request permits a built-in per-user installation flow, no paid installer/compiler dependency, elevation, policy bypass or public release. This remains an incomplete synthetic-data trial, not full134 acceptance.

Default/existing/--portable startup stays unchanged. New explicit --install copies only CI-published manifest-listed application/runtime/license files into a new per-user Programs/MemoApp/SyntheticTrial directory; source and destination files must be local regular paths without reparse points. Validate manifest exact version/path/hash/length/file-count/aggregate limits before staging; rehash each copy. Refuse existing destination; no update, overwrite or deletion of existing apps/data. Same parent staged directory moves into place after all copies verify; failures retain only new staged app files and report their path. No arbitrary process launch from manifest. Package checksum is corruption detection, not publisher authentication. No signing key/certificate created.

App confirmation names destination and synthetic-trial limitations. Create per-user Start-menu shortcut only after installation succeeds; shortcut errors leave a usable installed directory and report location. No automatic launch. Existing LocalAppData/MemoApp/SyntheticTrial vault and non-secret UI-device ID remain separate from installed executables. Uninstall instruction: close all windows, delete the installed application directory/shortcut manually; retain data unless user explicitly chooses otherwise. No scripted data deletion or uninstaller impersonation.

Required evidence: missing installer RED; actual temporary source/destination complete-copy/hash/Unicode-path behavior; bad manifest/path/duplicate/size/hash/missing-file/link/source-with-data refusal; occupied target preserving bytes; failed-copy retained stage/no automatic deletion; unchanged source; published self-contained manifest; actual per-user shortcut creation into temporary Windows fixture.
