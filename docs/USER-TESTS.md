# Windows 시험판의 최소 실제 사용자 확인

자동 Windows 검사와 아래 사용자 시험은 구분합니다. 실제 개인정보·기존 S메모 원본 대신 새 합성 메모만 사용하세요. 서명 없는 시험판이고 전체 134 기능 완료가 아닙니다. OS/회사 정책의 실행 차단을 우회하지 마세요.

1. ZIP 전체를 새 폴더에 해제합니다. `Install-User.cmd`로 새 사용자 폴더 설치와 시작 메뉴 실행을 확인하거나 `Start-Portable.cmd`로 실행합니다. 설치는 관리자 권한 없이 새 폴더에만 가능합니다. 기존 설치를 덮어쓰지 않습니다. 복구 비밀 생성·재입력 후 합성 메모를 만듭니다.
2. 실제 한글 IME로 관리창/포스트잇의 일반·서식·Markdown 문서를 편집합니다. 마지막 글자를 입력한 직후 파일 → 완전히 종료하고, 다시 실행·해제하여 마지막 수정과 서식/첨부가 남았는지 확인합니다.
3. 작은 RGB/RGBA 8-bit PNG를 첨부하고 선택 이미지 미리보기를 누릅니다. 선택 변경·분리·잠금 시 이전 이미지가 보이지 않는지 확인합니다. 제한 밖 PNG/JPEG는 미리보기를 거절해도 원본 첨부를 그대로 보존합니다.
4. 작은 합성 한글·영문 PNG에서 OCR 모델을 명시 설치/선택하고 글자 추출·결과 확인·새 메모 적용·검색·재실행을 확인합니다. 원본 Markdown/서식·첨부는 그대로여야 하며 선택 변경·취소·잠금 때 OCR 결과가 지워져야 합니다. 재실행 때 모델 사용은 다시 선택해야 합니다.
5. 실제 Windows 잠금과 5분 idle 후 관리창·포스트잇·달력·이미지가 가려지는지 확인합니다. 같은 복구 비밀로 다시 해제합니다. 실패하면 즉시 시험을 중단하고 합성 자료만 유지합니다.
6. 사용하는 모니터/DPI에서 포스트잇 이동·최소화·복원·재실행 위치를 확인합니다. 다른 PC/USB 이전이 필요하면 암호 백업 사본과 별도 보관한 복구 비밀로 새 시험 폴더에서 복구하고 원본은 보존합니다.
7. 트레이 상주를 켜고 관리창을 닫은 뒤, 트레이에서 관리창·새 메모·최근 메모를 여는지 확인합니다. 완전히 종료는 앱을 종료해야 합니다. Windows 시작 실행을 직접 켰다면 로그아웃·로그인 후 잠긴 상태로 시작되는지 확인하고, 시험 종료 전에 같은 설정을 끕니다. 실제 Windows 전체 종료 직전 마지막 합성 수정이 다음 실행에서 남는지도 확인합니다.
8. 합성 한글·한자·영문 메모를 PDF로 내보내 실제 사용하는 PDF 뷰어에서 열어 확인합니다. PDF는 평문이며 서식·첨부는 포함하지 않습니다. 지원하지 않는 emoji/복잡한 문자 조합은 파일 생성 전 거절해야 합니다. DOCX/XLSX를 사용한다면 실제 Office 프로그램에서도 기본 문자와 수식을 닮은 문자열이 그대로 보이는지 확인합니다. 시험용 평문 사본은 사용자가 직접 정리합니다.
9. 파일 경로 연결을 사용한다면 합성 외부 파일만 연결합니다. 연결 파일 열기는 명시 확인 뒤에만 실행되고, 분리는 원본 파일을 삭제하지 않아야 합니다. 외부 파일 자체는 앱으로 암호화되지 않습니다.
10. 휴지통 자동 정리는 합성 시험 폴더에서 기본 꺼짐·조건 확인 취소·7/30/90일 선택을 확인합니다. 설정을 켰다면 잠금·재실행 때 폴더 표시와 설정이 지워지는지 확인합니다. 실제 원본 자료로 자동 삭제를 시험하거나 컴퓨터 시간을 바꾸지 마세요. 실제 노후 휴지통 제거·백업 복구는 CI의 합성 날짜 자료로 검증했습니다.
11. 설치형 제거는 Windows 시작 실행 설정을 끄고 모든 창을 완전히 종료한 뒤 실행 파일 폴더 `%LOCALAPPDATA%\Programs\MemoApp\SyntheticTrial`과 시작 메뉴 바로가기만 수동 삭제합니다. 자료 폴더 `%LOCALAPPDATA%\MemoApp\SyntheticTrial`은 보존합니다. portable 자료는 실행 파일 옆의 `Data`입니다. 설치 폴더에서 portable로 실행했다면 해당 `Data`도 보존한 뒤 실행 파일만 제거하세요. 실패한 설치의 `.memo-install-*` 임시 앱 폴더는 안내된 위치를 확인한 후 수동 정리합니다.

최소 실제 확인은 새 폴더 설치/실행, 실제 한글 IME 마지막 수정 재실행, Windows 잠금과 현재 모니터의 화면 비노출, 합성 PNG OCR 및 자동 정리 설정의 잠금 후 해제입니다. 나머지는 사용하는 기능에 따라 확인하세요.

결과는 사용한 커밋/Windows 버전/설치형 또는 portable/모니터 DPI와 재현 순서로 기록하세요. 복구 비밀·암호 파일·실제 메모를 공개 이슈나 로그에 올리지 마세요.

후속 schema9 시험판에서는 합성 자료로 `재실행 뒤 이 기기에 복원`의 기본 꺼짐·명시 설정 저장·같은 폴더 재실행 복원·설정 해제를 확인합니다. 폴더 복사/후보 복구 뒤에는 다시 켜야 합니다. 시계 변경·실제 자료 삭제 시험은 필요하지 않습니다. Word 글자 서식·번호목록·표와 Excel 숫자 원문/TRUE/FALSE도 사용하는 실제 프로그램에서 확인하세요. 이 항목은 기존 d8bccaab ZIP에 포함된 기능이 아닙니다.
