# Windows 시험판 최소 실제 사용자 확인

새 합성 자료만 사용하고 ZIP 전체를 새 폴더에 해제합니다. 설치형은 Install-User.cmd, portable은 Start-Portable.cmd로 실행합니다. installation-manifest.json의 sourceCommit과 사용한 Windows 버전/설치 방식/모니터 DPI를 기록하세요. 기존 설치를 덮어쓰지 않고 자료 폴더·암호 백업·별도로 보관한 복구 비밀은 보존합니다.

1. **실제 한글 입력·잠금·DPI:** 관리창과 포스트잇에서 일반/서식/Markdown 및 이미지 주변 본문을 실제 IME로 수정하고 마지막 글자 직후 완전히 종료합니다. 재실행 때 마지막 내용·서식·첨부와 창 위치를 확인합니다. 사용하는 모니터/DPI, Windows 잠금과 5분 idle에서 관리창·포스트잇·이미지·위젯의 화면 비노출을 확인합니다.
2. **이미지·OCR:** 작은 합성 RGB/RGBA/gray/gray-alpha8 PNG를 명시 첨부/문서 추가/표시하고 두 창의 주변 본문·목록·표 편집과 Undo/Redo를 확인합니다. 선택·접기·숨김·잠금 때 이전 픽셀이 없어야 하고 블록 제거 후 첨부 원본·이력은 남아야 합니다. 실제 사용하는 작은 clipboard PNG/DIB 입력은 첨부 영역에서 확인합니다. OCR은 모델 명시 선택 뒤 취소·새 메모 적용·선택 메모 검색용 저장·검색·재실행을 확인합니다. 원본 본문/첨부와 다른 참조 메모는 유지돼야 합니다. 제한 밖 형식을 거절해도 원본 첨부는 보존돼야 합니다.
3. **실제 PDF·Word:** 일반 텍스트와 지원 서식 문단의 합성 한글/한자/영문/지원 emoji를 표시 PDF로 내보내 실제 뷰어에서 글자·굵게·밑줄·취소선·색·줄바꿈과 여러 문단의 페이지 순서를 확인합니다. 일반 텍스트와 서식 문단을 함께 선택한 순서도 확인합니다. 텍스트 PDF는 서식 없는 본문이며 표시 PDF는 A4·96 DPI 이미지로 검색·복사용 텍스트가 없습니다. 표시 PDF의 목록·체크리스트·표·이미지 문서·Markdown·링크 서식이나 지원 밖 글꼴/문자가 선택에 섞이면 전체를 파일 생성 전에 거절해야 합니다. 사용하는 Word 프로그램에서는 서식/목록/표/inline PNG DOCX의 순서·글자·투명도를 확인합니다. 내보낸 파일과 외부 뷰어 cache는 평문이며 사용자 소유입니다.
4. **백업·트레이·로그인·종료:** 새 암호 백업을 새 시험 폴더에서 복구하고 원본 자료를 보존합니다. 지속 백업 설정의 기본off/명시 설정/같은폴더 재실행/설정해제를 확인합니다. 트레이 상주를 직접 켜 관리창 숨김/다시열기와 완전히 종료를 확인합니다. 시작 실행을 선택했다면 실제 로그아웃/로그인 뒤 잠긴 시작과 설정 해제를 확인합니다. Windows 전체 종료 직전 마지막 합성 수정이 다음 실행에 남는지도 확인합니다. 자동 휴지통 정리는 합성 폴더에서 기본off/확인취소/7·30·90일 선택/잠금 설정정리만 확인하고 실제 원본·컴퓨터 시계 변경으로 시험하지 않습니다.

추가 사용하는 기능의 외부 파일 연결/Office/USB/다른 계정 수용도 해당 환경에서 확인합니다. 외부 파일 연결을 해제해도 원본 파일은 남아야 합니다. 설치 제거는 시작 실행을 끄고 완전히 종료한 뒤 실행 파일 폴더·바로가기를 정리하며 자료 폴더와 portable Data를 보존합니다.

실패는 sourceCommit/재현 순서/Windows 버전/설치 방식/DPI로 기록하고 합성 자료만 유지하세요. 복구 비밀·암호 파일·실메모는 공개 이슈/로그에 올리지 않습니다. 자동 검사, 광범위 OCR 품질, 전체134 기능 완료와 실제 사용자 수용은 각각 구분합니다.

N02 복구 소스의 PC 자동검사·설치 시험은 별도 PC 사용 승인 후 [PC 검증 안내](https://github.com/choehongseok/memo-app/blob/recovery/n02-20261012/docs/N02_PC_VALIDATION.md)의 고정 커밋·새 시험 폴더 절차로 진행합니다. 현재 소스 및 Linux 교차 빌드 결과만으로 실제 Windows 시험이 끝났다고 보지 않습니다.
